ApolloTune is a cutting-edge Progressive Web App (PWA) that bridges the gap between nostalgic analog radio and modern real-time social networking. Built with a focus on tactile immersion and low-latency interaction, it offers a "Digital-Analog" sanctuary for audio enthusiasts.

Features
Immersive Frontend Architecture: Leveraging VueJS and Tailwind CSS, the interface features a custom physics-based rotary tuner and a live digital-analog oscilloscope. This provides a tangible, responsive experience that mimics high-end vintage hardware.

Real-Time Audio Streaming: Utilizing WebRTC, ApolloTune delivers high-fidelity, low-latency audio broadcasting, ensuring a seamless "live" feel for every listener.

Bidirectional Social Layer: Beyond audio, the platform integrates Django Channels (WebSockets) to power a high-performance chat system, allowing for real-time community engagement during broadcasts.

Robust API Orchestration: A Django-based REST API serves as the backbone, managing complex data relationships, user authentication, and persistent storage with high reliability.
